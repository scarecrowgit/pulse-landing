What Pulse does

Everything between your data and a decision

Most small teams stitch together a BI tool, a database host and a web analytics script. Pulse is all three, and they already know about each other.

Dashboards without a data team

Pick a table and a measure, write SQL, or describe the chart in plain words. Pulse suggests a first dashboard from your tables.

Managed databases

PostgreSQL, ClickHouse, Cassandra and MongoDB. Small instances are ready in seconds; dedicated ones get reserved CPU and memory. Backed up daily.

Website and button tracking

One small script records visits, page views and clicks on any button you tag. Events land in a table you can join with orders.

Ask from ChatGPT or Claude

Turn on the built-in MCP server and AI assistants can read your dashboards and run read-only queries, with each person’s own permissions.

Alerts that explain themselves

Get a Slack message or email when a number crosses a line, with what changed and why, not just a red dot.

Open to extend

Public API, custom widgets and your own query engines when you outgrow the defaults.

Can I run Pulse on my own servers?

Yes. Self-hosted Pulse is the whole analytics tool: dashboards, query engine, tracking, alerts and the MCP server. It runs with Docker or Kubernetes, and nothing is sent back to us. Use Pulse databases alongside it, or only your own.

Needs 2 vCPU and 4 GB of memory to start.

# get the compose file and start Pulse
curl -fsSL https://get.pulse.app/compose.yml -o compose.yml
docker compose up -d

Questions people ask

What is Pulse?

Pulse is an analytics platform for small and medium businesses. It combines a dashboard builder and SQL query engine, managed databases, and website tracking, so a team can go from raw data to a live dashboard without a data team or several vendors.

Do I need to know SQL to use Pulse?

No. You can build charts by picking a table, a measure and a grouping, or describe what you want and Pulse writes the SQL. People who know SQL can write it directly.

Does Pulse copy my data?

No. Pulse queries connected databases where they are, with a read-only user, and keeps results for a few minutes to make dashboards fast. Data is only stored by Pulse if you use a Pulse database or website tracking.

Can I self-host Pulse?

Yes. The full analytics tool runs on your own servers with Docker or Kubernetes, including dashboards, the query engine, tracking, alerts and the MCP server. Nothing is sent back to Pulse.

Which databases can Pulse host?

PostgreSQL, ClickHouse, Cassandra and MongoDB, as a small shared instance that is ready in seconds or a dedicated instance with reserved resources.

Can ChatGPT or Claude read my Pulse data?

Yes, if you turn on the Pulse MCP server. Each person signs in with their own Pulse account, sees only what they can see in Pulse, and assistants run read-only queries by default.

Where is my data stored?

Pulse Cloud runs in Frankfurt (EU) or Virginia (US); you choose when you create a workspace. Self-hosted Pulse keeps everything on your servers.
